# HJC 传奇世界

一款用 TypeScript 和 Phaser 制作的俯视角单人冒险游戏。选一个职业，从银杏大主城出发，在平原、矿洞、村庄与沼泽之间探索，打怪、换装、完成小事件，再带着战利品回家。

这里有鸡群、煤岩怪、白猪族群和剑客，也有略带荒诞气息的地图与人物。项目正在逐步统一卡通像素美术、改善战斗反馈和探索体验，欢迎一起试玩、反馈和改进。

> 当前为持续开发版本。部分系统已可游玩，新加入的补给站等功能尚未完成完整流程验收；请先导出重要存档。

## 游戏特色

- **三种职业**：战士侧重近战和嗜血穿梭，法师侧重远程法术，道士侧重符咒、护盾与灵兽。
- **地图探索**：由基础区域逐步深入，包含矿洞、剑客村庄、白猪洞穴、湿地、草原、雨林及特色据点。
- **装备与成长**：打怪获取经验、金币和战利品，搭配装备，学习、配置和升级技能。
- **生活与休整**：主城提供购物、治疗、装备回收、技能学习等服务；宅院可休息与储物。
- **环境变化**：地图主题结合昼夜和天气调整画面与 UI 配色，可在设置中关闭环境配色。
- **探索小事件**：已有寻物、矿工救助、农田和湿地调查等可选目标。
- **小型补给站样板**：矿洞一层、剑客村庄和罗哥沼泽的部分小屋可进入，内有补给箱，并可能出现一只普通怪。
- **本地存档**：最多六个存档位，支持游戏内导出与导入。

## 开始游玩

### 使用打包版本

下载仓库 Releases 中维护者提供的版本（如已发布），解压后进入 `游戏` 目录，双击 `启动游戏.bat`，使用终端显示的网址进入游戏。服务运行期间保留终端窗口。

这是通过本地 HTTP 服务运行的网页游戏，请不要直接双击构建目录中的 `index.html`。

### 从源码启动

在包含 `package.json` 的源码目录运行。建议使用 Node.js 24 和 npm。

```bash
npm ci
npm run dev
```

打开终端打印的本地地址。停止开发服务使用 `Ctrl+C`。

```bash
# 类型检查
npm run typecheck

# 生产构建，输出到 dist/
npm run build

# 预览生产构建
npx vite preview --host 127.0.0.1

# 基础单元测试
npm run test:unit
```

`tests/` 中的浏览器脚本还包含本机浏览器路径和开发端口，运行前需要按自己的环境调整。基础单元测试不等于完整游戏验收。

## 基本操作

| 操作 | 按键或鼠标 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 点击目的地寻路 | 鼠标右键短按 |
| 持续朝鼠标方向移动 | 长按鼠标右键，移动鼠标可转向，释放停止 |
| 冲刺 | 双击同一方向键 |
| 普攻 / 选择攻击目标 | 空格 / 鼠标左键 |
| 使用技能 | 1、2、3；支持按住预览、松开释放，具体以界面提示为准 |
| 逃脱 | 按住 R 预览，松开释放；预览超过 2.5 秒取消 |
| 互动 | E |
| 背包 | B |
| 生命药水 / 消耗品列表 | Q / C |
| 范围拾取 / 一键装备 | X / F |
| 关闭当前窗口 / 暂停 | Esc |

技能与逃脱受冷却、资源和状态限制。确认弹窗支持空格或回车，Esc 取消。

## 第一次玩，可以这样开始

1. 建立新存档，选择职业并创建角色。
2. 跟随训练营练习移动、普攻、冲刺、技能、逃脱、职业被动和互动。被动练习步骤提供持续效果，完成或跳过后结束，不等于正式游戏中永久开启。
3. 到主城熟悉商铺、医馆、魔法屋和回收服务。技能需要在魔法屋购买与配置。
4. 从基础传送阵前往平原，先尝试少量普通怪，观察预警，再逐步探索其他区域。
5. 用 B 查看战利品；锁定想保留的物品，处理背包空间，远行前带上补给。

完整入门说明见 **[新手指南](docs/新手指南.md)**。

## 存档说明

存档保存在当前浏览器的本地存储中。不同浏览器、端口、域名或隐私窗口使用不同的存档空间，清理网站数据可能删除本地进度。

更新或换设备前，请从游戏的设置与存档界面导出备份，再在目标版本中导入。项目没有账号登录或云端存档承诺。

## 当前开发状态

已加入主城入口返回记录、宅院门外安全退出、主城局部美术样板、HUD 与主要面板整理，以及三张地图的地形与商人样板。近期还修改了传送后的首次冲刺处理和教程被动练习时长。

补给站采用独立记录：首次确定箱子内容和是否出现怪物，重复进出或读档不应重抽。当前每个存档的每座站只结算一次，未接入自动重置。

以下内容仍需继续开发或验证：

- 补给站完整战斗、读档、死亡与遗物回收流程。
- 全地图美术统一、更多建筑和自然地形细节。
- 将部分额外传送阵迁移为自然出口，以及一次性隐藏入口。
- 城池冒险扩展、可靠的通关宝箱结算。
- 装备对比、成长提示与死亡伤害来源反馈。
- 更多设备上的性能、窗口适配和长期存档兼容测试。

不将开发方向或静态预览计作已完成玩法。

## 源码导航

| 位置 | 内容 |
| --- | --- |
| `src/main.ts` | 主场景、战斗循环与现有界面入口 |
| `src/model.ts` | 角色、物品、存档及数据校验 |
| `src/content/` | 地图、职业、怪物等内容配置 |
| `src/features/`、`src/core/` | 功能扩展、事件、互动和面板注册 |
| `src/supply-stations.ts` | 小型补给站样板 |
| `src/return-routing.ts` | 入口与安全返回位置 |
| `src/monster-art.ts`、`src/merchant-art.ts` | 怪物与商人表现 |
| `src/town-art.ts`、`src/terrain-samples.ts` | 主城与地形样板 |
| `src/ui-rural-theme.ts`、`src/phase2-ui.css` | 主题与布局 |
| `public/` | 字体等静态资源 |
| `tests/` | 单元测试及开发用浏览器脚本 |

部分地图沿用了历史内部 ID，例如 `volcano` 对应“廖哥洞”、`ruins` 对应“矿洞二层”、`ice` 对应“矿洞三层”。修改环境时以显示名称和设定为准，避免破坏旧存档兼容。

## 反馈与贡献

欢迎通过 Issue 提交问题或建议。报告 Bug 时，请尽量附上：

- 版本、浏览器、系统和窗口尺寸；
- 所在地图、职业、等级和操作步骤；
- 预期结果、实际结果及截图；
- 是否使用过本地测试修改器，是否能在普通存档中复现。

提交修改前，请运行相关类型检查、构建与测试。涉及奖励、存档和地图连接时，请说明兼容方式；涉及战斗数值时，请提供修改依据。
